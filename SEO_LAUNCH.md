# SEO launch checklist

Post-deploy steps to grow organic traffic for Curl Cleaner.

## Search engine setup

1. **Google Search Console** — verify `https://curl-cleaner.rohitpatil.me`, submit `https://curl-cleaner.rohitpatil.me/sitemap.xml`, and request indexing for new pages:
   - `/copy-as-curl`
   - `/guide/clean-curl-for-llms`
   - `/guide/remove-headers-from-curl`
   - `/curl-to-fetch`
   - `/curl-to-python`
2. **Bing Webmaster Tools** — add the site and submit the same sitemap.

## Launch posts

- **Product Hunt** — launch as a developer tool with before/after curl examples.
- **Hacker News** — Show HN post focusing on token savings for LLM prompts.
- **Reddit** — `r/webdev`, `r/devtools`, `r/programming` (follow each sub’s self-promo rules).
- **dev.to / Hashnode** — republish the guide content (copy-as-curl, LLM token savings).

## Backlinks

- Add to relevant awesome lists (awesome-devtools, awesome-curl).
- Link from the GitHub repo README and set repo topics: `curl`, `devtools`, `seo`, `sveltekit`.
- Link from personal site `rohitpatil.me`.

## Validation

- [Google Rich Results Test](https://search.google.com/test/rich-results) — verify FAQPage, HowTo, BreadcrumbList on key pages.
- Social debugger — confirm `og.png` (1200×630) renders with `summary_large_image`.
- Monitor GA4 for landing-page traffic and Search Console for impressions/clicks by query.
